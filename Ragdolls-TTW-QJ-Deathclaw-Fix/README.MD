# Ragdolls TTW - Quarry Junction Deathclaw Crash Fix
Use this mod if you're crashing specifically when traveling to Quarry Junction, while using [Ragdolls](https://www.nexusmods.com/newvegas/mods/59147).

I tested using TTW, but not New Vegas by itself. But it should work ¯\_(ツ)_/¯

# Why?
TL;DR Three Deathclaws in Quarry Junction were missed in the original mod. And they had the new skeleton with the old ragdoll data. This sets them to use the new ragdoll data

# Installation 
Load this after the Ragdolls mod

# Hard Requirements
- [Ragdolls](https://www.nexusmods.com/newvegas/mods/59147) (TTW version, NV version probably works as well)
- (for ESPless version) [JIP LN NVSE](https://www.nexusmods.com/newvegas/mods/58277)
- (Optional) One of the Ragdolls TTW update patches on Nexus. I tested it using them and it still works.
